## Service menu demo

`service-menu-demo.png` captures the unchanged `paywall-bypass.user.js` from source commit `61ac5ac` running in headless Chromium on a synthetic article fixture. The fixture supplies a demo page and in-memory userscript storage adapters. The menu is opened with `Alt+Shift+M` using fresh settings; no reliability results are seeded and no external service is opened.

The page behind the menu is illustrative demo content. The floating button and scrollable service menu are the script's actual UI. This capture does not verify third-party service availability or a browser extension build.
